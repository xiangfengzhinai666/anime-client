## S7 讨论：数据源扩充

**来源**：S2.3 用户提出「热门番剧能不能照着 AniCh 的数据源更新，它的更全」，
当时结论是 AniCh 的后端闭源、我们只能用次元城 + B 站两个池子，
**等 S7（多源适配）时再讨论**。

**S7 要回答的问题**：

1. 首页"当季/热门"的候选池要不要从多个站点合并（每站一个 adapter）？
2. 合并时以谁为准：次元城（中文、能播）还是站点覆盖面（更全但可能没中文）？
3. 站点排行榜/周表各自的更新频率，是否需要缓存或定时刷新？
4. 同一部番在多个站点出现时，如何选"主条目"（现在按标题 + 年份 + 集数保守合并）。
