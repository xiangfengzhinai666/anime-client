# S3 报告：播放器

> 日期：2026-11-23 · 阶段：S3（播放器 + 源级登录 + 本地文件源）

## 一、做了什么

| 模块 | 内容 |
|---|---|
| 依赖体检 | `media_kit` 1.2.6 + `media_kit_video` 2.0.1 + libmpv/ANGLE（**仓库自带归档，构建不联网**） |
| 源级登录 | 次元城 **用户名 + 密码** 登录，token 存 **Windows 凭据管理器**，过期自动续期 |
| 播放地址 | `GET /api/v2/sections/{sectionId}/play-url` → 线路列表（兼容 3 种返回形状） |
| 播放页 | `/watch/{source}:{id}/{ep}`、`/watch/local?path=…` |
| 播放控制 | 播放/暂停、进度条（含拖动）、上/下一集、倍速（0.5–2.0）、音量、全屏、选集面板、线路切换 |
| 快捷键 | 空格/K 暂停、←/→ ±5s、J/L ±10s、↑/↓ 音量、M 静音、F 全屏、Esc 退出/返回 |
| 续播 | 每 5 秒写 `history`，进播放页自动 seek 上次位置 |
| 容错 | 未登录 → 引导登录；无线路 → 重试；播放错误 → 错误面板 |
| 本地文件源 | 设置 →「打开本地视频」（file_selector），不需要任何账号 |
| 详情联动 | 详情页「从第 1 集开始」和分集按钮直接进播放页 |

## 二、关键决策（含踩坑）

### 1. media_kit 的 libmpv/ANGLE 也会联网下载

`media_kit_libs_windows_video` 在 CMake 配置阶段从 **GitHub Releases** 下载
`mpv-dev-x86_64-….7z`（29 MB DLL）和 `ANGLE.7z`。本机 GitHub 直连不通，干净构建会挂。

**处理**：把两个归档（共 14 MB）放进 `windows/third_party/mpv/`，
在 `windows/CMakeLists.txt` 里于插件加载前 `configure_file` 拷到 `${CMAKE_BINARY_DIR}`。
插件会校验 MD5（`a832ef…` / `e866f1…`）——校验通过就跳过下载，直接解压。
与 S2 的 sqlite3 处理同一套路，**干净副本 40–55 s 构建，零下载**。

### 2. `flutter_secure_storage` 在这台机器编译不过

它的 Windows 实现需要 **ATL**（`atlstr.h`），本机 VS Build Tools 没装，编译直接失败。

**处理**：改用 `win32` 包直接调 **Windows 凭据管理器**
（`CredWriteW` / `CredReadW` / `CredDeleteW`，DPAPI 按当前用户加密）。
不新增原生依赖，token 依然加密落盘。

### 3. 登录用「用户名 + 密码」

抓站点前端 bundle 得到真实接口：

```
POST /api/auth/login      {username, password}        → {token, user, expires_at}
POST /api/auth/refresh    Authorization: Bearer ...   → {token, expires_at}
POST /api/v2/auth/register {username, password, email, email_code}
POST /api/auth/send-code   {email, type: register|reset}
```

实测：错误凭据返回 `401 invalid username or password`；传 `email` 字段会报
`Username is a required field` —— 确认是 **username** 而不是邮箱。

**为什么不用邮箱验证码登录**：站点登录本身就是用户名密码；验证码只用于注册/找回。
少一个邮件依赖，也少一条失败路径。注册入口后续放设置页说明（去官网注册）。

### 4. 登录态不共享

每个用户在自己的机器上登录自己的次元城账号；token 只在本机凭据管理器里，
不上传、不写日志、不进代码。

## 四、登录后仍不能播放：三个 bug（已修）

用户实测反馈「登录了还是提示需要登录」，排查出三个独立问题：

| # | 根因 | 现象 | 修法 |
|---|---|---|---|
| 1 | **token 自带 `Bearer ` 前缀**，发送时又拼了一次 → `Bearer Bearer eyJ…` | 所有鉴权请求 401，日志里根本没有 play-url 请求 | `CycaniSession.normalizeToken()` 统一剥前缀（登录/恢复/续期/发送四处） |
| 2 | **Riverpod 缓存了失败结果** | 登录前失败的错误被缓存，登录后重试仍是旧错误 | 播放页改用 `ref.refresh`；登录/退出时 `ref.invalidate(playLinesProvider)` |
| 3 | **启动时恢复登录态是异步的** | 冷启动后立刻点播放，会误判为未登录 | `CycaniAuth.ensureLoaded()`，取播放地址前显式等一次 |

**验证**：修复后 `cycani-play-url` 返回 200，播放《无职转生 第三季》第 1 集正常出画面
（`docs/assets/s3/3-online-play.png`）。

> 顺带确认：播放地址形如 `https://xxx.cycstream.com/<base64>.mp3?expires=…&md5=…`，
> 实际是 **mp4**（Content-Type `video/mp4`，文件头 `ftypisom`），扩展名是防盗链伪装，播放器按内容识别。

## 五、已知限制

## 六、S3.1 用户实测反馈的四个问题

| # | 反馈 | 根因 | 修法 |
|---|---|---|---|
| 1 | 按住右键应该 2 倍速 | 之前没做这个手势 | `Listener` 接管右键按下/抬起：按住 = 2.0x，松开还原原来的倍速 |
| 2 | 退出播放页（不退出软件）视频还在播 | `dispose` 里直接 `player.dispose()`，mpv 可能还在出声 | 先 `stop()` 再 `dispose()`；退出时保存进度也改为提前捕获保存函数（dispose 阶段再用 `ref` 会抛异常） |
| 3 | 重开软件同一集从头播 | 起播后立刻 `seek`，媒体还没解码完，seek 被忽略 | 先等 `duration` 出现（最多 10s）再 seek；起播后立刻记一次进度 |
| 4 | 只有次元城源能播放，其它都不能 | B 站/AniList 条目没有 `sectionId`，本来就没法换播放地址 | 详情页：非次元城条目把按钮换成「在次元城找这部」（按标题搜索并跳转），分集按钮置灰并给说明 |

**验证**：
- 续播：把某集进度预置成 600s 后启动播放，18 秒后数据库记录 606s（说明确实从 600 续上而不是从头）；
- 非次元城详情：截图 `docs/assets/s3/4-detail-other-source.png`，按钮显示「在次元城找这部」、分集置灰。

**仍需你确认**：右键 2 倍速、退出页面是否还出声（这两个要人手点）。


## 七、S3.2 播放自动找源 + 右键倍速

### 1. 「在次元城找这部」改为**自动找源**

用户反馈：多此一举，应该点「从第 1 集开始」就自动找能播的源。

现在详情页（**任意源**）：
- 按钮统一是「从第 1 集开始」，分集按钮全部可点；
- 点击后：先看是不是次元城条目（是就直接播），否则按 **中文名 → 日文原名/罗马音** 依次搜次元城，
  命中就跳播放页播对应集；
- 找不到时提示「没有找到可播放的源（次元城可能没有这部）」。

这是"多源"的最小可用形态：用户不用关心条目来自哪个站。

### 2. 右键按住 = 2 倍速（已用真实输入验证）

`Listener` 捕获 `WM_RBUTTONDOWN/UP`（位判断 `buttons & kSecondaryMouseButton`）：
按住把 `setRate` 设为 2.0，松开还原；右上角显示「2x 快进中」角标。

**验证方式**：用系统级 `SendInput` 模拟真实右键按住/松开，日志记录：

```
[play] hold-right down: rate 1.0 -> 2.0
[play] hold-right up: rate -> 1.0
```

> 关于"看起来像跳进度"：2 倍速是**改播放速率**，画面会明显加速；
> 如果网络跟不上，mpv 会先缓冲再往前跳，观感上像"跳了一下"。右上角的「2x 快进中」
> 角标可以用来确认当前确实处于 2 倍速状态。


## 八、S3.3 三处硬问题（用户实测：2 倍速无效 / 未响应 / 匹配错条目）

### 1. 右键 2 倍速"完全没反应"

**根因**：之前靠 Flutter 的指针事件，而窗口一旦不是前台（或焦点切换），Flutter 收不到右键事件。
实测：`initial focus=false`，`rbutton raw=true` 但事件没进来。

**修法**：不再依赖 Flutter 事件，改成**每 100ms 轮询系统右键状态**
（`GetAsyncKeyState(VK_RBUTTON)`）。按下 → `setRate(2.0)`，松开 → 还原；失焦时自动松开。

**验证**（日志 + 位置推进速度）：

```
hold-right: 2.0x（原 1.0）
tick pos=03:04.9 rate=2.0     ← 5 秒推进 10 秒
tick pos=03:14.9 rate=2.0
hold-right: 恢复 1.0 x
tick pos=03:24.4 rate=1.0     ← 回到 5 秒推进 5 秒
```

### 2. App "未响应"，只能任务管理器强杀

**根因**：鼠标在画面上移动会触发 `onHover → setState`，而每次 setState 都会
**重建 `Video` 控件**（media_kit 的纹理），高频重建把主线程/渲染线程拖死。

**修法**：
- `Video` 控件在 `initState` 里**只创建一次**，之后 build 直接复用同一个实例；
- 鼠标悬停做节流（500ms 内不重复 setState，且只在隐藏时显示）。

**验证**：60 秒高频鼠标移动 + 反复按住右键 + 3 次全屏切换，`Process.Responding` 始终 true，
内存稳定在 ~282–318 MB。

### 3. 自动找源匹配到剧场版

**根因**：直接取搜索结果第一条。搜"路人女主的养成方法"第一条是**剧场版 Fine**。

**修法**：候选条目按「年份 + 集数 + 是否剧场版 + 标题相似度」打分，取最高分：

- 剧场版/总集篇关键词（剧场版、Fine、Movie、完结篇）扣 6 分；
- 年份差 0 加 5 分、差 1 加 2 分、差更多扣 4 分；
- 集数一致加 4 分、差 ≤2 加 1 分、差更多扣 2 分；
- 标题相似/完全相同加分。


## 九、S3.4 「右键」其实是键盘 →  + 换源匹配修复

### 1. 键盘 → 的长按/短按

用户澄清：他说的「右键」是**键盘方向键 →**，不是鼠标右键。

现在的行为（`ArrowKeyHoldGesture`，350ms 阈值）：

| 操作 | 行为 |
|---|---|
| 短按 → | 跳 +5 秒（和以前一样） |
| 按住 → ≥350ms | 切 2 倍速，松开还原，不跳进度 |
| 按住期间的系统重复事件 | 忽略，不会重复触发 |

实现细节：
- 用 `HardwareKeyboard.instance.addHandler` **全局监听**（不再依赖 Focus，
  点了播放器里的按钮也不会失效）；
- 逻辑抽成独立类，配 4 个单测（短按/长按/自动重复/其它键）。

顺带保留：**鼠标右键按住**也能 2 倍速（轮询系统按键状态，实测有效）。

### 2. 换源匹配：标题带「。」就搜不到

用户反馈：「我的青春恋爱物语果然有问题」在次元城能搜到，但我们说找不到。

**根因**：B 站标题带句号（`…有问题。`），次元城搜索是精确匹配，多一个「。」就是 0 条。
实测：

```
「我的青春恋爱物语果然有问题。」 → total=0
「我的青春恋爱物语果然有问题」   → total=4
```

更极端的例子：「学生会有洞！」搜不到，因为次元城叫「学生会**也**有洞！」——
需要截短到「学生会」（3 字）才能命中。

**修法**（`lib/features/catalog/data/source_match.dart`）：
1. **查询词变体**：原文 → 去结尾标点 → 去「第 N 季/Season N」 → 去括号内容 → 截短 8/6/4/3 字；
2. **候选打分**：年份、集数、剧场版关键词、标题相似度加权，取最高分；
3. 命中分数足够高就提前结束，不再穷举所有变体。

**实测四个真实案例**（直接打站点 API 验证）：

| 条目 | 结果 |
|---|---|
| 我的青春恋爱物语果然有问题。 | ✅ 2013 / 13 话 |
| 路人女主的养成方法 | ✅ 2015 / 13 话（不是剧场版 Fine） |
| 学生会有洞！ | ✅ 学生会也有洞！2026 / 12 话 |
| 无职转生 第三季 ～到了异世界就拿出真本事～ | ✅ 2026 / 14 话 |


## 十、S3.5 键盘 2 倍速"只闪一下" + 单击暂停 + 去掉鼠标倍速

### 1. 长按 → 只触发一下又恢复

**根因**：上一版为了兼容"鼠标右键倍速"，加了一个每 100ms 的轮询；
它看到**鼠标**右键没按下，就把 `_holdingFastForward` 强制复位了。
键盘触发的 2 倍速因此 100ms 后就被自己人关掉。

**处理**：按用户要求**移除鼠标右键倍速**（连同轮询、`win32` 依赖、Listener 监听），
键盘 → 的长按 2 倍速不再被干扰。

### 2. 单击画面 = 播放/暂停

`GestureDetector.onTap` 从「显示控件」改成 `_togglePlay()`：

| 操作 | 行为 |
|---|---|
| 单击画面 | 暂停 / 继续 |
| 双击画面 | 全屏 |
| 鼠标移动 | 显示控件 |

（Flutter 的 tap 识别器带双击判定，双击不会先误触发暂停。）
