## 二、S3 期间修掉的问题（累计）

1. 登录 401 三连：token 自带 `Bearer` 前缀 / Riverpod 缓存失败结果 / 启动恢复竞态；
2. 退出播放页仍在出声（dispose 顺序 + dispose 里用 `ref` 抛异常）；
3. 续播无效（媒体未就绪就 seek）；
4. 非次元城源不能播（改为自动找源 + 匹配打分）；
5. 匹配到剧场版（查询变体 + 打分）；
6. 键盘 2 倍速只闪一下（鼠标轮询把状态复位，已整体移除鼠标倍速）；
7. App「未响应」（鼠标悬停导致 Video 控件高频重建；改为只创建一次 + 悬停节流）。

## 三、已知限制（不阻塞，记录在案）

1. **seek 后起播偏慢**：源站按偏移取流较慢，跳到中间位置会有几秒缓冲（UI 会转圈）；
2. 播放器未接弹幕（S4）；
3. 选集面板不支持自动连播；
4. 本地文件只支持单文件；
5. 只有次元城源可播（S7 多源）。
