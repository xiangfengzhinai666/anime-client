# S5 报告：追番 / 收藏 / 历史

> 日期：2026-11-24 · 数据库：schemaVersion **3** · 全部数据留在本机

## 一、做了什么

| 功能 | 位置 | 说明 |
|---|---|---|
| 追番三态 | 详情页「追番」按钮 | 想看 / 在看 / 看过，可随时改或取消；按钮直接显示当前状态 |
| 追番列表 | 侧栏「追番」 | 三个分类页签，卡片展示封面/标题/集数；菜单可改分类或取消 |
| 观看历史 | 我的 → 观看历史 | 按番去重，只显示最近一集；显示进度条；点一行直接续播 |
| 历史管理 | 历史页 | 单条删除（菜单）/ 一键清空（右上角，二次确认） |
| 播放设置入口 | 我的 → 播放与弹幕 | 之前是灰的，现在直达设置页 |

## 二、数据层改动

1. `history_entries` 与 `favorite_entries` 都新增 `source` 列（cycani / bili / anilist），
   历史页/追番页点进去才能拼出正确的 `source:id` 路由；
2. `schemaVersion` 2 → 3，迁移里 `addColumn`（不丢数据）；
3. `HistoryDao` 复用已有的 `removeEpisode` / `clearAll`；
4. 新增 `/history` 路由（shell 之外，独立 Scaffold）。

## 三、核验流程（建议按顺序点）

1. **追番**
   - 打开任意详情页 → 点「追番」→ 选 **在看**
   - 按钮应变成「在看」；侧栏「追番」→ 在看页签能看到它
   - 再点按钮 → 选 **取消追番** → 列表里消失
2. **追番列表**
   - 侧栏「追番」→ 切换 想看/在看/看过 三个页签
   - 卡片右上角菜单：改分类、取消追番
   - 点卡片 → 进详情页
3. **历史**
   - 我的 → 观看历史
   - 每部番只出现一次（最近那集），带进度条
   - 点一行 → 直接从那一集续播
   - 菜单 → 删除这条记录；右上角垃圾桶 → 清空（二次确认）
4. **回归**
   - 播放一集 → 关闭播放器 → 历史里该番排到最前
   - 一集播完（自动连播开着）→ 自动进下一集

## 五、已知限制

1. 追番与「播放进度」还没联动（不会自动把"看过"改成"看过"）；
2. 历史只记录在线播放（本地文件不写历史）；
3. 没有"排序/筛选/搜索我的追番"。

## 六、复查发现的问题（第二轮）

| # | 问题 | 严重度 | 处理 |
|---|---|---|---|
| 1 | 主键只有 `bangumi_id`：次元城 2109 和 B 站 2109 会互相覆盖 | **高（潜在）** | 主键改为 `(source, bangumi_id[, episode])`，schemaVersion 3 → 4，重建表迁移 |
| 2 | 追番状态只按 id 匹配，同 id 不同源会串 | 中 | 改为按 `(source, id)` |
| 3 | 历史去重只按 id，同 id 不同源会被合并成一条 | 中 | 改为按 `source:id` |
| 4 | 删历史/取消追番只按 id 删，可能删错源 | 中 | `remove` / `removeEpisode` 都带 source |
| 5 | 历史里 B 站/AniList 条目点了会跳播放（播不了） | 中 | 非次元城源改为跳详情页，由详情页自动找源 |
| 6 | 历史行显示「第 1 集 · 第01集 · 25%」，集标题重复 | 低 | 集标题是「第NN集」格式时不再重复显示 |
| 7 | 追番/取消追番没有任何反馈 | 低 | 加 SnackBar（「已加入在看」「已取消追番」） |
